# Student-Recommendation-System-project
🎓 Student Recommendation System The Student Recommendation System is an intelligent application designed to assist students in making informed academic and career decisions. Leveraging data analysis and machine learning, this system provides personalized recommendations for courses, learning resources, career paths.

The **Education Recommendation System** is an intelligent machine learning application that helps students choose the most suitable academic subjects based on their personal profile, academic performance, and lifestyle factors.It analyzes multiple features such as grades, study time, health, attendance, and free time to generate personalized subject recommendations along with confidence scores.

---

## 🚀 Features

- 📊 Personalized subject recommendations
- 🤖 Machine learning based prediction model
- 📈 Confidence score for each recommended subject
- 📉 Visual insights using graphs and charts
- 🧠 Feature importance analysis
- 🖥️ Interactive user interface
- ⚡ Real-time prediction

---

## 🛠️ Tech Stack

- **Python**
- **Machine Learning (Scikit-Learn)**
- **Pandas & NumPy**
- **Matplotlib / Seaborn**
- **Streamlit (for UI)**

---



## 🧠 How It Works

1. User enters profile details (age, grades, study time, etc.)
2. Data is preprocessed and fed into the ML model
3. Model predicts the most suitable subjects
4. Results are displayed with confidence scores
5. Feature importance graph explains decision factors
